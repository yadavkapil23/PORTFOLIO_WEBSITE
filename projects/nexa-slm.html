The Concept

NEXA is a GPT-style autoregressive language model built from the ground up — no AutoModelForCausalLM, no GPT2LMHeadModel, no pretrained Transformer implementation. Every component was implemented and verified by hand: token and positional embeddings, causal self-attention, grouped-query attention (GQA), Transformer decoder blocks, AdamW optimization, checkpointed GPU training, autoregressive generation, and a deployed Gradio demo. It was trained on the TinyStories dataset using a single NVIDIA T4 GPU on Google Colab's free tier.

Project Structure

  • config.py — model + training hyperparameters
  • tokenizer.py — GPT-2 BPE tokenizer (tiktoken, encode/decode only)
  • dataset.py — text → token windows → DataLoader
  • embeddings.py — token + positional embeddings
  • attention.py — causal self-attention, causal masking, multi-head attention
  • gqa.py — grouped-query attention
  • transformer.py — feed-forward network, LayerNorm, Transformer decoder block
  • model.py — SmallGPT: full model assembly + parameter counting
  • train.py — training loop, GPU device handling, checkpointing
  • checkpoint.py — save/load model + optimizer state
  • generate.py — autoregressive generation with temperature + top-k sampling
  • evaluate.py — loss / perplexity evaluation
  • app.py — Gradio web app

Each file includes TODO(you) comments marking the parts worth tracing by hand to understand the mechanics, and every file's if __name__ == "__main__": block runs standalone as a sanity check.

Quickstart — Overfit a Tiny Dataset

pip install -r requirements.txt
python train.py

This trains on data/tiny.txt (4 lines) — training loss should drop close to 0, confirming the model can memorize a tiny dataset before scaling up to TinyStories.

Training on TinyStories (Colab T4)

Download and flatten TinyStories:

python prepare_tinystories.py --output data/tinystories.txt --num-stories 500000

Train (auto-detects CUDA):

from train import train
model, tok = train(data_path="data/tinystories.txt")

Checkpoints save every checkpoint_interval steps — resume with:

train(data_path="data/tinystories.txt", resume_from="checkpoints/ckpt_stepXXXX.pt")
